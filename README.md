
# KeenKeeper — Relationship Tracker

KeenKeeper is a responsive relationship-tracking web application built with React. It helps users organize contacts, record interactions and review relationship activity.

## Live Website

https://keenkeeper-tau.vercel.app

## Main Features

- Track friends and personal connections
- Log calls, text messages and video interactions
- View interaction timelines with filters
- Review activity statistics
- Responsive interface

## Technology Stack

- React
- JavaScript
- Tailwind CSS
- React Router
- Vite
- Browser LocalStorage

## Main Dependencies

- react
- react-dom
- react-router-dom
- lucide-react
- react-icons
- react-hot-toast
- recharts
- tailwindcss

See `package.json` for the complete dependency list.

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Saklainmostak-learner/-keenkeeper.git
```

2. Open the project:

```bash
cd -keenkeeper
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal.

## Available Scripts

- `npm run dev` — Development server
- `npm run build` — Production build
- `npm run preview` — Preview production build
- `npm run lint` — Run ESLint
